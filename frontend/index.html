Секреты без ручной возни

Откройте SOPS-файл из подключённого каталога или git-репозитория. Редактор расшифрует его в памяти, а сохранение зашифрует обратно с теми же получателями и правилами .sops.yaml.

sops …

Не знаете, с чего начать? Инструкция: подключение sops, ключи, файлы с компьютера →

ENC[AES256_GCM,data:••••]

Файл должен лежать внутри смонтированных каталогов. Путь можно вставить из проводника сервера или локального Docker-тома.

HTTPS: укажите SOPS_EDITOR_GIT_TOKEN на сервере. SSH: host ~/.ssh монтируется в /ssh. Если указать папку, скачивается только она (плюс корневые файлы вроде .sops.yaml), а не весь репозиторий.

Выберите файл на компьютере

Зашифрованный файл расшифруется в памяти и откроется в редакторе; открытый YAML/JSON/dotenv/INI откроется как есть, а «Зашифровать» в редакторе создаст SOPS-версию.

Или перетащите файл сюда. Зашифрованный откроется после ввода ключа, открытый — сразу в редакторе.

Не знаете, как зашифровать файл и какой ключ выбрать? Документация: файл с компьютера. Ключ расшифровки задаётся в разделе «Ключ» — серверный ключ не обязателен.

    Приватный ключ

    Ключ хранится только в памяти процесса и привязан к cookie этой вкладки. Он не пишется на диск и не попадает в логи. Ключ вкладки имеет приоритет над серверным, поэтому после его ввода файлы, зашифрованные только на серверный ключ, перестанут открываться — нажмите «Забыть ключ», чтобы вернуться к серверному.

    Серверный ключ (зашифрованное хранилище)

    Ключ можно только заменить, прочитать его нельзя. Он хранится зашифрованным в /data/server-key; мастер-ключ задаётся секретом SOPS_EDITOR_KEYSTORE_KEY. При активном ключе вкладки сначала нажмите «Забыть ключ».

    Открывайте утилиту по HTTPS или на localhost: ключ и открытый текст идут по сети.

    Склонированные репозитории

    Зашифровать файл

    Файл шифруется на сервере и остаётся только шифротекстом: из загруженного файла открытый текст удаляется сразу. Исходный файл на компьютере не меняется.

    sops updatekeys / rotate

    Ключи файла

    Перешифровывает только ключ данных: значения не меняются, получатели берутся из .sops.yaml.

    Новый ключ данных: все значения перешифровываются, MAC пересчитывается.
